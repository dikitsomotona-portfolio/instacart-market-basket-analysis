# Instacart Market Basket Analysis

## Project Overview

This project applies Python-based data analytics techniques to the Instacart grocery shopping dataset.

The analysis explores customer purchasing behaviour, product trends and relationships between products using exploratory data analysis and statistical inference.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab
* Google Drive

## Project Work

The project is divided into several analytical stages:

* Project setup and understanding of the dataset
* Exploratory Data Analysis (EDA)
* Continuous inference
* Advanced statistical inference
* Chi-Square Goodness-of-Fit testing
* Chi-Square Test of Independence

## Analysis Areas

The analysis focuses on understanding:

* Customer purchasing patterns
* Product and order behaviour
* Distribution of variables
* Relationships between categorical variables
* Statistical significance of observed patterns
* Evidence-based conclusions from the dataset

## Project Outcome

The project demonstrates the use of Python and statistical analysis techniques to explore a large retail dataset and derive insights from customer purchasing behaviour.

## Dataset

The project uses the Instacart grocery shopping dataset provided for the analysis.

The original dataset files and intermediate/processed data files are not included in this repository. The notebooks contain the Python code used to load, clean, transform and analyse the data, while the `outputs/figures` folder contains the generated visualisations and analysis results.
